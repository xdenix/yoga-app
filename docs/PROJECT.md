# YogaApp — описание проекта (актуально на 2026-10-28)

## Кратко

Android-приложение «Йога — 30 дней» (Kotlin + Jetpack Compose): персональный 30-дневный план, библиотека асан, сессия с таймером и TTS, фоновые мелодии, кастомизация дня. Бренд сплэша: **ДенисМурыс-Йога**.

Репозиторий исходников: **https://github.com/xdenix/yoga-app** (публичный, ветка `main`).

## Для кого этот документ

Для человека или **агента-разработчика**, который продолжает работу без полного контекста чата. Код в репозитории важнее этого файла, если они расходятся.

## Текущее поведение (as-built)

1. **Онбординг** — выбор уровня (новичок / средний / продвинутый) → генерация 30-дневного плана.
2. **Программа** — список дней, прогресс, переход в день / сессию.
3. **День** — состав поз, длительность, swap/delete/reorder, старт сессии.
4. **Сессия** — таймер, озвучка позы (TTS), выбор мелодии, фото позы.
5. **Библиотека / свой день / настройки** — просмотр поз, конструктор дня, тема, сброс прогресса, мелодия.
6. **Сплэш** — анимированный лотос + подпись «ДенисМурыс-Йога».
7. **Обновление** — проверка последнего GitHub Release и установка APK (после разрешения пользователя/системы). Автопроверка в `MainActivity.onResume` + ручная кнопка в Настройках → «Обновления» → «Проверить обновления».

## Технические факты

- `applicationId`: `com.example.yogaapp` (+ `.debug` в debug).
- `compileSdk` / `targetSdk` 35, `minSdk` 26.
- Room + KSP: в `gradle.properties` стоит `ksp.useKSP2=false`.
- Позы: ~**42** в `PoseLibrary` (не 40, как в старом README).
- Иллюстрации: JPEG в `assets/poses/` (~1.9 МБ суммарно), UI через Coil в `PoseFigure`.
- Мелодии: **5 суфийских треков** в `assets/melodies/*.mp3` (источник: Freesound, CC0 — пользователь `nesibe`: sounds 171927, 171928, 172368, 183938, 183939). `PracticeMelodyPlayer` — loop, volume 0.32. + опция Off.
- Сеть: есть `INTERNET` для GitHub updater (практика йоги по-прежнему offline-first по данным).
- Версия кода: `versionCode 3` / `1.0.2` (проверять `app/build.gradle.kts`).

## Архитектура

Single-module MVVM + UDF:

- `data/` — Room, DataStore, audio, repository, DI (Hilt)
- `domain/` — модели, use cases, `Result`/`AppError`
- `ui/` — экраны Compose + ViewModels
- `update/` — GitHub self-update

Тесты: JUnit 5 в `app/src/test` (`.\gradlew.bat testDebugUnitTest`).

## Дистрибуция

| Канал | Статус |
|--------|--------|
| GitHub Releases | **основной** — APK asset, автообновление в приложении |
| Google Play | **отложен** пользователем; `com.example.*` для магазина не подходит без смены id |

Имя asset для автообновления: `yoga-app-{versionCode}-{versionName}-debug.apk`.

## Ограничения и договорённости с заказчиком

- Не менять package / структуру без необходимости.
- Не коммитить APK в git.
- Минимальные правки «по задаче».
- Play self-update заменён на GitHub.
- Фото поз — студийный стиль (серый комплект, светлый зал) по референсу пользователя.

## Как поднять с нуля

1. JDK 17 + Android SDK 35.
2. Клонировать `https://github.com/xdenix/yoga-app.git`.
3. Создать `local.properties` с `sdk.dir=...`.
4. `.\gradlew.bat assembleDebug`.
5. Установить APK на устройство/эмулятор `YogaTest`.
